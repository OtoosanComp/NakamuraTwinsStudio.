# Nakamura Twins Studio — Clean Starter

Base mínima reconstruida desde cero para la primera versión funcional.

## Funciones
- Interfaz adaptable a móvil.
- Selector de estilo Tsuki / Yami.
- Importación de una foto local.
- Dos ajustes básicos de color con Canvas.
- Exportación a JPG.
- Procesamiento local; no se envían fotos a un servidor.
- Capacitor y workflow para APK de depuración.

## Workflow de GitHub
Sube el contenido de esta carpeta a la raíz de un repositorio vacío. Abre Actions y ejecuta `NTS Android APK`; también corre automáticamente en cada push a `main`.

## Identidad Android
- `appId`: `com.otoosan.nakamuratwinsstudio`
- Nombre: `Nakamura Twins Studio`

La APK de debug no es una versión para Play Store.
